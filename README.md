# KITA-Q OVERRIDE（アルファ版）

お上品（クリーン）に漂白された街を、修羅（ヤンキー）で上書きするオープンワールド・アクション。
three.js によるブラウザ向け 3D 実装です。外部アセットは使わず、テクスチャもすべてプログラムで生成しています。

## プレイ

**▶ https://kt2reft.github.io/kita-q-override/**

PC（キーボード＋マウス）、スマホ・タブレット（タッチ）、ゲームパッドに対応しています。
スマホは横向き（ランドスケープ）推奨。視点の感度はタイトル画面のスライダーで調整できます。

## ローカルで起動

```bash
python server.py
```

`http://localhost:5173/` を開いてください（Windows では `start.bat` のダブルクリックでも起動）。
three.js を CDN から読み込むため、インターネット接続が必要です。

## 操作

| 操作 | キーボード＋マウス | ゲームパッド | スマホ（タッチ） |
| --- | --- | --- | --- |
| 移動 | WASD | 左スティック（アナログ） | 画面左下をなぞる（仮想スティック） |
| 視点 | マウス / 矢印 | 右スティック | 画面右側をなぞる |
| 攻撃・使用 | クリック / J | RT | 「攻撃」ボタン |
| ダッシュ / 歩き切替 | Shift / C | LT / L3 | 「走」（トグル）/「歩」 |
| ジャンプ・パラグライダー展開 | Space | A | 「跳」 |
| 強制給餌テイクダウン | F | B | 「給餌」 |
| 乗る・調べる / 降りる | E | X | 「使用」/「降」 |
| ヤンキー座り | G | Y / 十字↓ | 「座」 |
| 武器切替 | 1〜5 / Q | LB・RB・十字←→（十字↑で素手） | 画面下の武器リストをタップ |
| 操作説明 / ポーズ | H / P | SELECT / START | 画面上の ？ / II |

ビークル搭乗中：アクセル・ブレーキは W/S・RT/LT・「アクセル」「ブレーキ」、ハンドルは A/D・左スティック・仮想スティック、
サイドブレーキは Space・A・「ドリフト」、太鼓の衝撃波は クリック/F・B・「太鼓」。
パラグライダー中：A/D・スティックで旋回、W/S・RT/LT・「急降下」「フレア」。

タッチとパッドでは、画面に出る操作ガイドの表記（「E 乗る」→「X 乗る」「使用 乗る」）も自動で切り替わります。
スマホ・タブレットでは既定の画質を「軽量」にし、群衆と交通量も控えめに自動調整します。

## 実装済みシステム

- **1.1 Infection System**：`Infection_Meter` → `OnYankeeFied`（見た目変更・陣営変更・BT切替・ボイス）
- **1.2 施設ハッキング**：ダンプ突入（ImpactVelocity > 500）またはカップ酒で「角打ち」化、BGMクロスフェード、半径50mの修羅ゾーン
- **2.1 ごぼ天ソード**：先端ほど強いノックバック、強制給餌テイクダウン（10秒気絶）
- **2.2 小倉祇園太鼓チャージ**：ドリフト特化ハンドリング、半径20mの衝撃波で盆踊りスタン5秒
- **3.1 / 3.2 交通**：信号機破壊で `bIsRegulated = false`、ヤンキー横断（Force_Brake・睨みつけ）
- **4. MQ_05「成人式は金ピカだろ！」**：乱入 → 強制カラーリング（50/100）→ 占拠 → 完了ムービー
